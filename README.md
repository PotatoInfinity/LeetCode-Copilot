# **LeetCode-Copilot**

An extension that helps you solve LeetCode problems with AI-powered suggestions.

## Installation

### **1. Clone the repository**

```bash
git clone https://github.com/PotatoInfinity/LeetCode-Copilot.git
```

### **2. Get a Google Gemini API Key**

Generate one from [Google AI Studio](https://aistudio.google.com/api-keys)

### **3. Load the extension in Chrome**

1. Open [`chrome://extensions/`](chrome://extensions/)
2. Enable **Developer mode** (top-right)
3. Click **Load unpacked**
4. Select the cloned `LeetCode-Copilot` folder

### **4. Enter your API Key**

1. Click the LeetCode-Copilot extension icon in Chrome
2. Paste your Gemini API key

## Usage

1. Open **LeetCode**
2. Click the **Solve** button
3. A suggestion sidebar will appear—powered by your Gemini key

## Enjoy!
